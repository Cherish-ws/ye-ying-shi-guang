# 夜萤拾光

网页端 Canvas 肉鸽小游戏：暗夜花园拾取光尘、进阶三选一、微光切换、Boss 快慢刀、余烬商店。

## 本地运行

用浏览器直接打开 `index.html`，或：

```bash
npx serve .
# 或任意静态服务器
```

## 操作

| 输入 | 作用 |
|------|------|
| WASD / 方向键 | 移动 |
| 鼠标移动 | 悬停跟向移动（无需按住） |
| 鼠标按住拖动 | 全屏浮动摇杆（更稳） |
| 空格 | 闪耀 |
| E / Q | 光脉（充满后） |
| Shift | 冲刺（需「瞬影」） |
| P | 暂停 |

触屏：左下技能键 + 摇杆 / 右侧拖动。

## 目录

- `index.html` — 入口
- `style.css` — 界面
- `game.js` — 游戏逻辑

## 说明

- 存档在浏览器 `localStorage`
- 与 `douyin/` 抖音小游戏工程相互独立
